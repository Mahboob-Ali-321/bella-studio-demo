# Bella Studio Demo

Create a professional, elegant demo website for a fictional unisex salon called "Bella Studio" — this is a PORTFOLIO/SAMPLE site meant to showcase to potential salon clients what I can build for them, so it should look polished and complete, not tied to any single real business.

BRAND IDENTITY:

- Color palette: deep plum/burgundy background with gold accents, or alternatively a warm cream and rose-gold palette (pick whichever looks most premium) — this should feel high-end and adaptable, since I'll be re-skinning colors/logo per client later

- Typography: elegant serif for headings, clean sans-serif for body text

- Tone: premium, warm, trustworthy — the kind of site any salon owner would look at and think "I want something like this"

SECTIONS TO INCLUDE:

1. HERO — headline like "Look Your Best, Every Day" with a strong CTA ("Book Appointment"), hero image of a salon interior or styling shot (use a placeholder/stock-style image)

2. ABOUT — short warm paragraph about the salon's philosophy and experience

3. SERVICES — grid of service cards: Haircut & Styling, Hair Color, Hair Spa & Treatments, Bridal Makeup, Waxing & Facial, Manicure/Pedicure — each with icon, short description, and a "Book Now" link

4. GALLERY/PORTFOLIO — a clean photo grid section showcasing styled looks (placeholder images)

5. TESTIMONIALS — 3-4 sample review cards with star ratings

6. CONTACT/BOOKING — embedded map placeholder, WhatsApp button, contact form (Name, Phone, Service, Preferred Date, Message), business hours

7. FOOTER — logo, quick links, social icons, address

TECHNICAL REQUIREMENTS:

- Fully mobile responsive, no horizontal scroll, clean hamburger menu on mobile

- Smooth scroll-triggered fade/slide-up animations on sections as they come into view

- Hover animations on buttons and service cards (subtle scale/glow)

- Fast loading, clean code structure so it's easy for me to swap out colors, logo, text, and images later for different client pitches

The goal: this should be a complete, professional, ready-to-show demo that proves what a real client's website could look like — polished enough to send as a live link during outreach.
